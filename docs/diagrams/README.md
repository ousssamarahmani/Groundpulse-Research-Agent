# Architecture Diagrams

## GroundPulse GCP Integration Architecture

The **target** GCP integration architecture is available in two forms:

| Asset | Purpose |
|---|---|
| [Editable Mermaid source](gcp_integration_architecture.mmd) | Update the architecture as implementation decisions change. |
| [Rendered PNG](../../assets/diagrams/groundpulse-gcp-integration-architecture.png) | GitHub-visible image embedded in the [GCP Integration Plan](../GCP_REALTIME_INTEGRATION_PLAN.md). |

The rendered diagram was visually verified for dark-background contrast and labels the approved-source, intake, research, evidence, and analytics paths. It is intentionally marked as a **target architecture**: none of the displayed GCP services should be interpreted as currently deployed unless implementation evidence is added to the repository.
